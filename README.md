# GooseDroid 🐻

용량이 커서 소스 코드를 realeases에 올렸습니다.
다른 앱 위(오버레이)에서 곰 캐릭터가 혼자 돌아다니는 안드로이드 앱입니다.
손가락으로 잡아서 옮길 수 있고, 머리 위에 말풍선으로 대사를 띄울 수 있습니다.

> AISW 캡스톤 디자인 I · 이음미 팀

## 다운로드

빌드된 APK와 프로젝트 파일은 용량이 커서 저장소에 포함하지 않았습니다.
**[Releases](../../releases)** 에서 최신 버전을 받아 주세요.

- `GooseDroid.apk`: 바로 설치해서 써 볼 수 있는 파일
- 소스 압축 파일: 안드로이드 스튜디오에서 열어 빌드할 수 있는 프로젝트

> APK는 출처를 알 수 없는 앱 설치 허용이 필요할 수 있습니다.

## 지금까지 구현한 기능

| 기능 | 설명 |
|---|---|
| 캐릭터 활성화 | 홈 화면의 스위치 하나로 켜고 끔 |
| 자율 배회 | 1.5~5초 머물렀다가 화면 안의 무작위 지점으로 걸어가는 동작을 반복 |
| 드래그 이동 | 곰을 손가락으로 잡고 화면 어디로든 옮길 수 있음. 놓으면 2초 뒤 다시 돌아다님 |
| 잡혔을 때 모션 | 잡고 있는 동안 바둥거리는 이미지로 바뀜 |
| 말풍선 | 곰 머리 위에 표시. 자리가 없으면 아래쪽에 표시. 글자 수에 따라 3~12초 후 사라짐 |
| 터치 투과 | 곰 바깥을 터치하면 뒤에 있는 앱으로 그대로 전달 |
| 백그라운드 동작 | 포그라운드 서비스로 동작. 앱을 닫아도 계속 움직임 |
| 화면 상태 연동 | 화면이 꺼지면 멈추고, 켜지면 다시 시작해서 배터리 절약 |
| 자동 재시작 | 켜 둔 상태에서 재부팅하거나 앱을 업데이트하면 자동으로 다시 시작 |
| 상단 알림 | 동작 중 알림에서 앱 열기, 끄기 가능 |

## 사용 방법

1. 앱을 실행합니다.
2. **캐릭터 활성화** 스위치를 켭니다.
3. "다른 앱 위에 표시" 권한을 허용하고, 다시 스위치를 켭니다.
4. (Android 13 이상) 알림 권한을 허용합니다.
5. 곰이 화면 위를 돌아다닙니다. 끄려면 스위치를 끄거나 알림의 **끄기**를 누릅니다.

## 말풍선 사용법 (API 연동용)

다른 코드에서 `GooseOverlayService.say()`만 호출하면 말풍선이 뜹니다.
어느 스레드에서 호출해도 됩니다.

```java
GooseOverlayService.say("안녕! 오늘 날씨 좋다");  // 말풍선 표시
GooseOverlayService.say(null);                    // 말풍선 즉시 지우기
```

- 서비스가 꺼져 있으면 호출은 무시됩니다.
- 4줄을 넘는 글은 말줄임표로 잘립니다. 짧게 보내 주세요.

## 프로젝트 구조

```
app/src/main/
├─ java/com/cfks/goosedroid/
│  ├─ MainActivity.java                  # 활성화 스위치, 권한 요청
│  ├─ BearView.kt                        # 곰 그리기, 드래그 감지
│  ├─ BubbleView.kt                      # 말풍선 그리기
│  └─ overlay/
│     ├─ GooseOverlayService.java        # 포그라운드 서비스, 배회, 드래그, 말풍선 제어
│     └─ OverlayAutostartReceiver.java   # 재부팅/업데이트 후 자동 시작
├─ res/
│  ├─ drawable/                          # 곰 이미지, 앱 아이콘
│  ├─ layout/activity_main.xml           # 홈 화면(스위치 하나)
│  └─ values/                            # 문구, 테마
└─ AndroidManifest.xml
```

## 빌드 방법

1. Realeases의 소스 코드를 내려받아 압축을 풉니다.
2. 안드로이드 스튜디오에서 **File → Open** 으로 프로젝트 폴더를 엽니다.
3. Gradle Sync가 끝나면 기기나 에뮬레이터를 고르고 **Run** 을 누릅니다.

| 항목 | 값 |
|---|---|
| minSdk | 24 (Android 7.0) |
| targetSdk / compileSdk | 36 |
| Android Gradle Plugin | 8.12.0 |
| 언어 | Java, Kotlin |

SDK 36이 없으면 **Tools → SDK Manager** 에서 설치하세요.

## 권한

| 권한 | 용도 |
|---|---|
| `SYSTEM_ALERT_WINDOW` | 다른 앱 위에 곰 표시 |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE` | 백그라운드에서 계속 동작 |
| `POST_NOTIFICATIONS` | 동작 중 알림 표시 |
| `RECEIVE_BOOT_COMPLETED` | 재부팅 후 자동 시작 |
| `INTERNET` | 이후 API 연동을 위해 선언 (현재 네트워크 통신 코드는 없음) |

## 알려진 한계

- Android 12 이상에서는 터치를 통과시키는 말풍선 창의 투명도를 0.8로 제한해야 해서 말풍선이 살짝 비쳐 보입니다.
- 삼성, 샤오미 등 일부 기기는 절전 설정 때문에 서비스가 종료될 수 있습니다. 설정에서 이 앱의 배터리 사용을 **제한 없음** 으로 바꿔 주세요.
- 잠금화면 위에는 표시되지 않습니다.
- 말풍선은 아직 외부에서 `say()`를 호출해야 뜹니다. 자동으로 대사를 만들어 주지는 않습니다.
